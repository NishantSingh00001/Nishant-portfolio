## How it's built

One hand-written `index.html` (HTML, CSS and JavaScript) with GSAP, ScrollTrigger and Lenis for animation, and self-hosted fonts (Geist, Geist Mono, Instrument Serif). The "Read the code" section loads my public repositories from the GitHub API on every visit, so new repos show up automatically. It falls back to a saved list if the API is unavailable.

Deployed on Netlify from this repository (no build step).
